How to use Mermaid (free)

Mermaid costs $0. Open-source (MIT). No account required for basic use.

  • This page — diagrams render via CDN below (works offline after first load if cached).
  • mermaid.live — paste code, export PNG/SVG (free).
  • GitHub / GitLab — fenced ```mermaid blocks in markdown render automatically.
  • VS Code / Cursor — install "Mermaid" extension (free); preview in editor.
  • Notion, Obsidian — native or plugin support.

Example — copy into mermaid.live:

flowchart LR
  Damage[Damage brush] --> TopoR[topo.R erodes]
  Heal[Heal mode] --> TopoA[read topo.A doctrine]
  TopoA --> Restore[Restore admissibility]
  Restore --> Wave[Collapse wave propagates]

Mermaid Cloud paid tiers exist for team features — you do not need them.
